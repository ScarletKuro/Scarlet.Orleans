# In-box Orleans ADO.NET streaming scripts (vendored)

The schema scripts of `Microsoft.Orleans.Streaming.AdoNet`, which the package does not ship, used only to set up the
in-box provider for comparison. The `*-Main.sql` scripts they build on are the persistence benchmark's.

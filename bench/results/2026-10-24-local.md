# Local results, 2026-10-24

Two consecutive runs on one developer machine: Windows 11, 16 logical processors, Docker Desktop containers on the same
machine (PostgreSQL 17.11, SQL Server 2022, MySQL 8.4.13) with default settings, and a SQLite file in WAL mode. Client
and databases share the machine, so the numbers compare providers with each other, not with a production deployment.
Run-to-run differences of up to about 10% are noise; the SQLite ADO.NET insert p50 of the first run is a warm-up outlier.

The in-box provider is `Microsoft.Orleans.Persistence.AdoNet` 10.4.0 with its default options. SQLite has no in-box
column, because the in-box provider supports SQLite through System.Data.SQLite only.
